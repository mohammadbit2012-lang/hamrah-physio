# همراه فیزیو (Hamrah Physio)

سامانه جامع مدیریت کلینیک فیزیوتراپی و پرونده الکترونیک سلامت (EMR)
A Comprehensive Physiotherapy Clinic Management System & Electronic Medical Record (EMR) System.

## ویژگی‌ها (Features)
- مدیریت پرونده کامل بیمار و ثبت گزارش‌های استاندارد SOAP
- مدیریت نوبت‌ها، زمان‌بندی کلینیک و گاه‌شماری ویزیت‌ها
- داشبورد EMR چندرسانه‌ای با Bento Grid
- پشتیبانی کامل از زبان فارسی و چیدمان راست‌به‌چپ (RTL)
- پشتیبانی از تم‌های روشن و تیره (Light/Dark Mode)
- برنامه‌های تمرینی خانگی، سوابق بالینی و پیگیری فاکتورها و مالی

## راهنمای اجرا (Getting Started)

1. مطمئن شوید فلاتر (Flutter SDK >= 3.2.0) بر روی سیستم شما نصب است.
2. دریافت وابستگی‌ها:
   ```bash
   flutter pub get
   ```
3. اجرای برنامه:
   ```bash
   flutter run
   ```
4. ساخت نسخه اندروید (APK):
   ```bash
   flutter build apk --release
   ```
